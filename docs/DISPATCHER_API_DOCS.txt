## 1. Dashboard & Statistics

### 1.1. Get Dashboard Overview Stats

**Method:** `GET`  
**Path:** `/dispatcher/dashboard/stats`  
**Description:** Lấy tổng quan số liệu thống kê cho Dashboard.

**Response:**
```json
{
  "totalOrders": 1245,
  "pendingOrders": 45,
  "activeOrders": 132,
  "completedToday": 89,
  "onlineDrivers": 67,
  "openTickets": 15
}
```

## 2. Order Management

### 2.1. Monitor Orders (List Orders)

**Method:** `GET`  
**Path:** `/dispatcher/orders`  
**Query Params:**
- `status` (optional): `PENDING` | `ACTIVE` | `ALL` | `COMPLETED` | `CANCELLED`

**Response:**
```json
[
  {
    "id": "64f5...",
    "from": "123 Nguyễn Văn Linh",
    "to": "456 Trần Duy Hưng",
    "status": "PENDING",
    "customerName": "Nguyễn Văn A",
    "customerPhone": "0901234567",
    "createdAt": "2024-01-01T10:00:00.000Z",
    "priority": "VIP"
  }
]
```

### 2.2. Get Order Details

**Method:** `GET`  
**Path:** `/dispatcher/orders/:id`  
**Description:** Xem toàn bộ thông tin chi tiết của một đơn hàng.

**Response:** Full Order Object (customerId, driverId, locations, items, notes, status, history...)

### 2.3. Manual Dispatch (Assign Driver)

**Method:** `POST`  
**Path:** `/dispatcher/assign`  
**Payload:**
```json
{
  "orderId": "64f5...",
  "driverId": "64f5..."
}
```

## 3. Special Trip Management

### 3.1. Get Special Orders

**Method:** `GET`  
**Path:** `/dispatcher/orders/special`  
**Description:** Lấy danh sách các đơn hàng "Đặc biệt".

**Response:**
```json
[
  {
    "id": "64f5...",
    "from": "...",
    "to": "...",
    "status": "PENDING",
    "priority": "VIP",
    "specialNote": "Hàng linh kiện điện tử",
    "tags": ["VIP", "FRAGILE"],
    "customerName": "...",
    "createdAt": "..."
  }
]
```

### 3.2. Mark Order as Special

**Method:** `POST`  
**Path:** `/dispatcher/orders/:id/mark-special`  
**Payload:**
```json
{
  "priority": "VIP" | "URGENT" | "FRAGILE",
  "specialNote": "Ghi chú cho tài xế",
  "tags": ["VIP", "FAST"]
}
```

### 3.3. Unmark Special Status

**Method:** `POST`  
**Path:** `/dispatcher/orders/:id/unmark-special`

## 4. Driver Management

### 4.1. View Driver Locations (Map View)

**Method:** `GET`  
**Path:** `/dispatcher/drivers`  
**Query Params:** `lat`, `lng`, `radius`

**Response:**
```json
[
  {
    "id": "64f5...",
    "name": "Nguyễn Văn B",
    "location": { "lat": 21.0244, "lng": 105.8587 },
    "status": "ONLINE",
    "phone": "0987654321"
  }
]
```

### 4.2. Get All Drivers (List View)

**Method:** `GET`  
**Path:** `/dispatcher/drivers/all`  
**Description:** Lấy danh sách toàn bộ tài xế (dùng cho Dropdown chọn tài xế trong trang Báo cáo).

**Response:** `DriverMapResponseDto[]`

### 4.3. Get Driver Performance Stats

**Method:** `GET`  
**Path:** `/dispatcher/drivers/:id/performance`  
**Query Params:** `from`, `to` (YYYY-MM-DD)

**Response:**
```json
{
  "driverId": "64f5...",
  "totalTrips": 150,
  "completedTrips": 145,
  "cancelledTrips": 5,
  "rating": 4.8,
  "totalEarnings": 15000000,
  "acceptanceRate": 95
}
```

## 5. Support & Issue Tracking

### 5.1. Get Support Tickets

**Method:** `GET`  
**Path:** `/dispatcher/support`  
**Query Params:** `status` ("OPEN", "IN_PROGRESS", "RESOLVED", "CLOSED")

**Response:**
```json
[
  {
    "id": "64f5...",
    "user": "Trần Thị C",
    "phone": "0912345678",
    "content": "Tài xế đến muộn",
    "status": "OPEN",
    "createdAt": "2024-01-01T10:00:00.000Z",
    "orderId": "64f5..."
  }
]
```

### 5.2. Update Support Ticket (Issue Tracking)

**Method:** `PUT`  
**Path:** `/dispatcher/support/:id`  
**Payload:**
```json
{
  "status": "IN_PROGRESS" | "RESOLVED" | "CLOSED",
  "note": "Ghi chú diễn biến xử lý sự cố",
  "resolution": "Hướng giải quyết sau cùng"
}
```
