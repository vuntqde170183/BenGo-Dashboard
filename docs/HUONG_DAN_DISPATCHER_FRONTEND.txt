export const dispatcherApi = {

4.1. QUẢN LÝ ĐƠN HÀNG (Monitor & Special)
-----------------------------------------
● Mô tả UI: Giao diện bảng (Table) với Tab navigation. Tab [Đặc biệt] hiển thị các đơn có badge priority (VIP/Urgent).

● Phân tích Thành phần (Components):
  1. StatCards (Thành phần tóm tắt): Hiển thị các ô số liệu nhanh (Đơn chờ, Đơn đang chạy, Đơn cần xử lý gấp).
  2. TabNavigation: Bộ lọc trạng thái đơn hàng (Tất cả, Chờ gán, Đang đi, Hoàn thành, Đặc biệt).
  3. Search & Filter Bar: Tìm kiếm theo mã đơn hoặc SĐT khách hàng.
  4. OrderTable (Thành phần chính): 
     - Hiển thị danh sách đơn hàng với các cột: ID, Khách hàng (Tên/SĐT), Lộ trình, Trạng thái, Thời gian tạo.
     - PriorityBadge: Hiển thị icon/màu sắc khác biệt cho đơn hàng VIP/Urgent.
  5. ActionButtons: Nút điều hướng nhanh đến trang "Phân chuyến" (cho đơn PENDING) hoặc "Đánh dấu đặc biệt".

● API & Data Flow:
  1. API chính: `dispatcherApi.getOrders(status)`
     - Method: `GET`
     - Params: `status` (PENDING, ACTIVE, ALL...)
  2. Data Source (Nguồn dữ liệu):
     - Dữ liệu gốc lấy từ Collection `Order` trong Database.
     - Thông tin Khách hàng được `populate` từ Collection `User`.
     - Thông tin Tài xế (nếu có) được `populate` từ Collection `Driver`.
  3. Cơ chế cập nhật: 
     - Sử dụng Polling (setInterval 30s) để đảm bảo danh sách Monitor luôn mới nhất.
     - Khi chuyển Tab, Reset page và fetch lại dữ liệu theo status mới.

● Phân mục: Quản lý Chuyến Đặc Biệt (Chức năng 4)
-----------------------------------------
● Phân tích Thành phần (Components):
  1. SpecialOrderTable: Một view riêng hoặc tab riêng hiển thị các đơn hàng có `priority !== 'NORMAL'`.
  2. MarkSpecialModal (Thành phần quan trọng nhất): 
     - Select Box: Chọn mức độ ưu tiên (VIP, URGENT, FRAGILE).
     - TextArea: Nhập ghi chú đặc biệt (ví dụ: "Cần tài xế mặc đồng phục", "Hàng linh kiện điện tử").
     - TagInput: Nhập các nhãn phân loại để lọc nhanh (ví dụ: #SieuToc, #DienTu).
  3. ActionButtons: 
     - [Hủy đặc biệt]: Để đưa đơn hàng về trạng thái bình thường.
     - [Sửa thông tin]: Để cập nhật lại ghi chú/mức độ ưu tiên.

● API & Data Flow:
  1. Fetching: `dispatcherApi.getSpecialOrders()`
  2. Execution: 
     - `dispatcherApi.markSpecial(orderId, payload)`: Khi Dispatcher muốn nâng cấp một đơn thường lên đặc biệt.
     - `dispatcherApi.unmarkSpecial(orderId)`: Khi không cần chế độ giám sát đặc biệt nữa.
  3. Data Source (Nguồn dữ liệu):
     - Các trường `priority`, `specialNote`, `tags` được lưu trực tiếp trong Document của `Order`.
     - Dispatcher có quyền ghi đè (Overwrite) lên các trường này thông qua API.

● Logic nghiệp vụ:
  - Một đơn hàng được coi là "Đặc biệt" khi nó có giá trị `priority` khác `NORMAL`.
  - Trên giao diện Monitor, các đơn này phải luôn nổi bật (Blinking hoặc dùng màu vàng/đỏ) để Dispatcher ưu tiên gán tài xế tốt nhất.

● Code React mẫu:
-----------------------------------------
import { useState, useEffect } from 'react';
import { dispatcherApi } from '@/services/api/dispatcherApi';

export default function OrdersPage() {
  const [orders, setOrders] = useState([]);
  const [activeTab, setActiveTab] = useState('ALL');

  useEffect(() => {
    const fetchOrders = async () => {
      const data = activeTab === 'SPECIAL' ? await dispatcherApi.getSpecialOrders() : await dispatcherApi.getOrders(activeTab);
      setOrders(data);
    };
    fetchOrders();
    const interval = setInterval(fetchOrders, 30000); // Tự động làm mới mỗi 30s
    return () => clearInterval(interval);
  }, [activeTab]);

  return (
    <div>
      <div className="tabs">
        {['ALL', 'PENDING', 'ACTIVE', 'SPECIAL'].map(tab => (
          <button key={tab} className={activeTab === tab ? 'active' : ''} onClick={() => setActiveTab(tab)}>{tab}</button>
        ))}
      </div>
      <table>
        <thead><tr><th>ID</th><th>Từ</th><th>Đến</th><th>Trạng thái</th><th>Thao tác</th></tr></thead>
        <tbody>
          {orders.map(o => (
            <tr key={o.id}>
              <td>{o.id}</td><td>{o.from}</td><td>{o.to}</td><td>{o.status}</td>
              <td><button onClick={() => {/* Mở Modal Đánh dấu Đặc biệt */}}>Đánh dấu VIP</button></td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}

  1. API Fetching: `dispatcherApi.getDriverPerformance(driverId, from, to)`
     - Method: `GET`
     - Params: `driverId` (định danh tài xế), `from/to` (khoảng thời gian báo cáo).
  2. Logic xử lý:
     - Mặc định khi vào trang hiển thị dữ liệu 30 ngày gần nhất của tài xế đầu tiên trong list.
     - Khi thay đổi bất kỳ filter nào (Driver hoặc Date), ứng dụng sẽ trigger call API mới.
  3. Data Source (Nguồn dữ liệu):
     - Backend thực hiện tính năng Aggregation (tổng hợp) từ Collection `Order` và lấy thông tin sao từ Collection `Driver`.

● Ý nghĩa nghiệp vụ: 
  - Giúp Dispatcher đưa ra quyết định dựa trên dữ liệu (Data-driven decision) để thưởng cho tài xế tích cực hoặc nhắc nhở tài xế có tỷ lệ hủy đơn cao.

● Mô tả UI: Màn hình trung tâm chỉ huy. Hiển thị các khối chỉ số quan trọng (KPI Cards) và danh sách các "điểm nóng" cần chú ý.

● Phân tích Thành phần (Components):
  1. KPI Grid: Bộ 4-6 thẻ số liệu (Total, Pending, Active, Online Drivers). Mỗi thẻ có màu sắc cảnh báo riêng.
  2. LiveStatusBanner: Thanh thông báo chạy ngang hiển thị các sự kiện mới nhất (ví dụ: "Có 1 đơn VIP mới vừa được tạo").
  3. OperationChart: Biểu đồ đường thể hiện tần suất đơn hàng theo giờ trong ngày.
  4. QuickLinkPanel: Các nút tắt dẫn nhanh tới: [Giao nhanh đơn chờ], [Xem tài xế gần nhất], [Xử lý hỏa tốc].

● API & Data Flow:
  1. API chính: `dispatcherApi.getDashboardStats()`
  2. Data Source: Tổng hợp (Aggregated) từ Order, Driver và SupportTicket collections.
  3. Cơ chế cập nhật: Polling 30s hoặc dùng Webhook/Socket nếu muốn Real-time tuyệt đối.

● Code React mẫu:
-----------------------------------------
import { useState, useEffect } from 'react';
import { dispatcherApi } from '@/services/api/dispatcherApi';

export default function DashboardPage() {
  const [stats, setStats] = useState(null);

  useEffect(() => {
    const fetchStats = async () => {
      const data = await dispatcherApi.getDashboardStats();
      setStats(data);
    };
    fetchStats();
    const timer = setInterval(fetchStats, 30000);
    return () => clearInterval(timer);
  }, []);

  if (!stats) return <div>Đang tải...</div>;

  return (
    <div className="p-6">
      <h1 className="text-2xl font-bold mb-6">Bảng điều phối trung tâm</h1>
      <div className="grid grid-cols-3 gap-4">
        <div className="card bg-blue-100 p-4">Đơn đang chạy: {stats.activeOrders}</div>
        <div className="card bg-yellow-100 p-4">Đơn đang chờ: {stats.pendingOrders}</div>
        <div className="card bg-green-100 p-4">Tài xế Online: {stats.onlineDrivers}</div>
      </div>
      {/* Thêm Chart và Recent Activities ở đây */}
    </div>
  );
}
